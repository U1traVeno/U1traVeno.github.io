## 发生了什么

暑假，做导论，直播，招新，倒闭，然后发现身边的人怎么全去写 Rust 和 Web 3 了。

对于我自己这边，花了一段时间什么代码都没写，重构出 Paramer V2，也许有了自己的一思考软件架构的思路。

国庆，去西安玩，乡下孩子第一次坐飞机。其实过去最多的活动是各种各样的碳水美食。

买了个 macbook，好用。11 月份左右开始写 Stripe 应用的 Python 后端模块外包，同时 Paramer 后端开始新增两位人手。这两件事情都有大量的信息值得学习，不仅是技术方面。

此时本以为可以两面开弓，然而是有意外的。工作进行了一周，开会同步时才发现找来的某所 985 大学某大二学生实际上没有任何实际产出，最后导致我给他兜底。与此同时 Paramer 实际上还存在各种打包之类的杂活，实际上并不能完全脱离开。同时还有大量诸如上课和乒乓球约课，必须跑满的阴暗长爬等琐事...

因此这一个多月的工作量是爆掉的，一天掰成两天用。每天八点两眼一睁就是出宿舍，晚上踩着十一二点的门禁才回宿舍，期间是高强度的代码工作，有课就带着 mac 去教室签到，没课就带着 mac 在瑞幸书吧。总之宿舍是能不呆就绝对不呆。

合租了个房子，除了有点偏，晚上广场舞有点吵以外，都比宿舍好太多了。

两遍都做的差不多，喘了两口气，又开始研究怎么做这么大一坨的 Python 应用的加密打包。研究一半还没完呢，期末了。算了算，发现期末还是得一天掰成两天用。

列了个复习计划，考了一半才发现不应该忽视睡觉时间和为了保证不掉 san 的休息时间，最后放弃掉大物和信安数学，准备签个到直接补考。

为什么不是信号与系统？因为旭哥为了让我不挂科，给我补了三天的私塾，把学校教法 500G 的信息量压缩成 50K 教给我，自己在脑子里解压，直接速通完了，再挂科就丢脸了。甚至直到考试才知道信号与系统用的是英文卷子，也还是过了。期末两周过的像两个月。

到写这一篇的时候，在干一些开发无关的杂活和面对奇怪的需求补奇怪的特性的杂活，闲时用 golang 写某个~~直播音频语义事件触发引擎~~。
